# 0.3.1 — 2026-07-26

## Fixed

- **`OFF_RATE_LIMIT_PRODUCT`** — default lowered from `100` to `15` requests/min, matching the 15 req/min/IP Open Food Facts documents for `GET /api/v*/product`. The prior default authorized exceeding the published ceiling, which Open Food Facts answers with an IP ban rather than a throttle. Operators running their own Product Opener instance can still raise it via the env var. ([#21](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/21))
- **README.md, docs/design.md, docs/idea.md, `server.json`** — corrected the four documentation references that still stated the old `100`/min product-read default.

## Changed

- **`docs/design.md`** — documents that the taxonomy tier calls `search.openfoodfacts.org` (search-a-licious), a separate deployment the published Open Food Facts limits do not name and for which no limit is documented, so its `10`/min default is a conservative local choice rather than a mirror of a published figure. The text and tag search paths share one budget, so requests reaching the endpoint the documented 10/min covers stay within it regardless of how a query routes.
