# 0.3.2 — 2026-08-24

## Changed

- **`@cyanheads/mcp-ts-core` `^0.11.0` → `^0.12.3`** — adopts SDK v2 and MCP 2026-07-28 compatibility; unknown root-level tool arguments are now rejected by name before the handler runs instead of being silently discarded.
- **Session mode** — Docker and the environment reference now select `stateless` explicitly, while documenting that the framework's `auto` default resolves to `stateful`.
- **Framework integration** — upstream request helpers now receive the SDK v2 context directly with correlation metadata carried through `withExtra`, and TypeScript typechecks both source and tests while the build emits source only.
- **Tool descriptions** — user-facing guidance names Open Food Facts behavior directly instead of exposing internal backend terminology.
- **Toolchain** — Bun and both Docker stages move to `1.4.0`; the multi-architecture build stage uses `BUILDPLATFORM`, production installs omit optional peers, and framework scripts and skills are re-synced.
- **Security contact** — vulnerability reports now use `security@caseyjhand.com`.
