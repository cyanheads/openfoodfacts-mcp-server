# 0.3.3 — 2026-09-17

## Added

- **`nutrient_filters` on `off_search_products`** — per-100g numeric range constraints (`{ nutrient, operator, value }`, `lt`/`lte`/`gt`/`gte`) across nine indexed fields, ANDed with every other filter (#28).
- **`last_page` output field** — the deepest reachable page of a result set, so a positive-total page past the end can point back at real results instead of reading as a zero-match search (#24).
- **`text_index_snapshot` enrichment field** — discloses when a response was answered by the text backend's index, which lags the live database (#31).

## Changed

- **`off_browse_taxonomy` embedded sample** — 52 non-canonical category/label/allergen IDs replaced with their canonical Open Food Facts tag key or dropped where none exists; human synonyms ("shellfish", "cookies", "gluten free") still resolve via a non-exported aliases field (#30).
- **`sort_by` now applies on text searches** — forwarded to search.openfoodfacts.org with the `-` prefix it requires for descending order, instead of being silently dropped whenever `query` is set (#33).
- **`additives_tag` and the text-search page window** now key on routing to the text backend (`query` or `nutrient_filters`), not on `query` alone.
- README reorganized into an Overview/Capability-reference layout; issue templates route framework-vs-server bugs and add a security-advisory contact link; `.claude-plugin/plugin.json` gains a schema reference, author contact, and keywords.
