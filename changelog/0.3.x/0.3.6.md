# 0.3.6 — 2026-09-22

## Added

- **`off_search_products` gains `traces_tag`, `exclude_allergens`, `exclude_traces`, and `ingredients_analysis_tag`** — the last a closed enum of the 12 vegan/vegetarian/palm-oil verdicts Open Food Facts computes; `labels_tag` also takes an array of up to 10 values that must all apply. Every response carrying an exclusion gets an `exclusion_coverage` caveat, since a product with no allergen or trace data entered passes it (#41).

## Changed

- **`off_search_products` text queries now require every word to match**, ranked across the 31 languages the text index analyzes rather than English only — a product named only in French or Russian is now found by that name (#38, #47).
- **Tag filter values on the text path are canonicalized** before being sent as exact-match clauses — a case variant, synonym, or singular resolves to its canonical ID the way `/api/v2/search` already does (#39).
- **Tag-only searches are capped at page 10**, the deepest page Open Food Facts serves an anonymous client; `last_page` reports the reachable depth instead of the request failing unpredictably deeper in (#44).
- **`off_get_product` and `off_compare_products` accept every barcode Open Food Facts serves** (4–40 digits after leading zeros), not just 8–14-digit codes — a 7-digit code returned by `off_search_products` previously had no way back into `off_get_product` (#46).
- Package tagline corrected from "search by ingredient" to "search by keyword, tag, allergen, or nutrition filter" — `off_search_products` never filtered on ingredient text.

## Fixed

- **`off_search_products` drops rows stored under a barcode Open Food Facts cannot serve** instead of returning one `off_get_product` would reject; `omitted` discloses how many were left off the page (#35).
