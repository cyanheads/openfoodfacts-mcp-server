# 0.3.0 — 2026-07-26

## Added

- **`off_browse_taxonomy`** — a search term now resolves against the live Open Food Facts taxonomy (`search.openfoodfacts.org/autocomplete`) for the five open facets (`categories`, `labels`, `allergens`, `additives`, `countries`), merged behind the embedded offline sample. Fixes ordinary terms (hummus, tofu, kombucha, pizzas) dead-ending on the 79-entry embedded category list. ([#14](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/14))
- **`OFF_RATE_LIMIT_TAXONOMY`** env var (default `10`/min) — taxonomy resolution's own rate-limit tier, separate from the search budget.
- **`off_browse_taxonomy`** enrichment gains a `notice` field: names whether an answer came from the offline sample, a failed live lookup, or a genuine no-match, so an empty result is never read as an authoritative "no such tag."

## Changed

- **`off_browse_taxonomy`** — `nova_groups` tag IDs are now bare digits (`1`–`4`) instead of `en:1`–`en:4`, matching what `off_search_products`' `nova_group` enum accepts and the bare-letter convention `nutrition_grades` already used. The previous IDs were rejected outright by `off_search_products`. ([#15](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/15))
- **`off_browse_taxonomy`** — `total_in_facet` is now omitted for the five live facets, since the autocomplete endpoint reports no match total and cannot be enumerated. Still returned for the closed `nova_groups`/`nutrition_grades` vocabularies.
- **`off_browse_taxonomy`** — `annotations.openWorldHint` flips to `true`.
