# 0.3.4 — 2026-09-17

## Added

- **`traces_tags`, `ingredients_analysis_tags`, `countries_tags` on `off_get_product`** — the "may contain" allergen warning, the computed vegan/vegetarian/palm-oil verdict, and countries of sale, each resolvable through `fields` subsets like every other field (#32).

## Fixed

- **`off_get_product` field subsets now fetch their dependencies** — requesting `nutriments` also fetches `serving_size`/`serving_quantity`/`serving_quantity_unit` so per-serving figures carry a denominator, and `serving_quantity_unit` fetches the quantity it describes. The heading no longer reads `## Unknown product` when `product_name` was simply outside the requested subset (#23).
- **`off_compare_products` no longer reports an all-failed batch as "no products found"** — the zero-found summary now distinguishes barcodes that failed to fetch from barcodes Open Food Facts confirmed missing, and skips the retry suggestion when every failure is a non-retryable `upstream_rejected` (#29).
- **Crowd-sourced text is escaped before it reaches `content[]`** — product names, ingredient text, tag IDs, and grades can carry Markdown metacharacters that previously altered the rendered structure (headings, table columns, an unterminated code fence). `structuredContent` is unaffected; a new `src/utils/markdown.ts` holds one escaper per rendering context (#27).
- **Rate limiters now charge one budget slot per upstream HTTP attempt, not per tool call** — a charge previously covered the retry boundary's up-to-4 attempts, so a failing upstream could send 4x the configured per-minute ceiling before the limiter noticed. A budget exhausted mid-retry now fails fast with `rate_limited` instead of sleeping out the retry window (#25).
- **`structuredContent.error.data` no longer carries `body`, `responseBody`, `statusCode`, `statusText`, or `errorSource`** — these mirrored a spread of the framework's raw fetch-error diagnostics, including the upstream response body twice, and could hand a client a rendered Open Food Facts error page. The published contract is now an explicit allowlist (`status`, `retryAfter`, `retryAttempts`, `operation`, plus per-call context); a client reading the dropped fields sees them disappear (#26).
