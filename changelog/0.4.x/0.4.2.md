# 0.4.2 — 2026-11-01

## Added

- **Local export mirror** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): setting `OFF_MIRROR_PATH` keeps a SQLite copy of the Open Food Facts export. `off_get_product` and `off_compare_products` read it first by barcode and read live for a barcode it lacks. `bun run mirror:init`, `mirror:refresh`, `mirror:status`, and `mirror:verify` build and inspect the store from a checkout or the Docker image, and the server refreshes it every three hours. With the variable unset nothing opens or schedules.
- **Mirror-served tag-only searches** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): `off_search_products` with tag filters alone is served from the mirror when every tag value is confirmed, with an exact `total` through its first 10,000 results. Under the default order, `popularity_key`, and `unique_scans_n` the mirror sorts by the values stored with each record, so the order can differ from a live search.
- **`source`, `mirror_as_of`, `mirror_snapshot`** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): product, compare (per row), and search results name `off_api` or `off_mirror`; a mirror answer also carries when the copy was last updated and a note saying so.
- **`stored_as_sold`** ([#73](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/73)): when an `off_get_product` or `off_compare_products` read returns only prepared figures, one follow-up read fetches the record's stored as-sold set and fills the as-sold fields. The field reports `read`, `none`, or `unread` with a `reason`; an unread set never fails the call.
- **`cause` on `lookup_failed`** ([#77](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/77)): a failed taxonomy lookup reports `budget_spent`, `rate_limited`, or `unavailable`, and the exclusion refusal, the zero-result notice, and the `off_browse_taxonomy` notice name it, blaming the vocabulary only for `unavailable`.
- **`unconfirmed[]` on `page_out_of_range`** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): a tag-only page past 10 that the ready mirror cannot take because a value went unconfirmed is refused with those values named, and is retryable when each failed only at lookup.

## Changed

- **`retryAfter`** ([#76](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/76)): published in whole seconds on every failure that knows its wait. Each `failed[]` entry of `off_compare_products` carries it, and a retryable `unrecognized_exclusion` refusal carries the longest wait among its unchecked values.
- **`off_compare_products` stored sets** ([#73](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/73)): a row whose stored as-sold set was read stays in the as-sold table even when that set fills none of the compared columns.
- **Docs and skill**: tool descriptions, the server instructions, the `openfoodfacts-guide` skill, and the README describe the mirror, stored sets, and failure causes.

## Fixed

- **Shared taxonomy lookups** ([#75](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/75)): a caller that joined a lookup whose starter cancelled restarted it with a fresh 20 s deadline and could outlast 55 s. It now restarts with what is left of its own, so a single call settles within 55 s. A joined caller that is itself cancelled now ends at once instead of waiting for the shared answer.
- **Brand values with a language prefix** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): `xx:nutella` and `en:nutella` now drop the prefix before slugging. The text-search path had sent `xx-nutella` since 0.3.6.
- **Mirror sync and serving** ([#79](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/79)): a sync that lost its lease writes no sync state. The serving process waits at most 250 ms on a sync's write lock when opening the store and never creates one at a path that does not exist.

## Dependencies

- **`node-cron`** ^4.6.0 (added, runs the scheduled refresh).
- **`better-sqlite3`** ^13.0.3 (added, dev; SQLite for the Node test lane).
- **`tsc-alias`** held at ^1.9.9 on the `devcheck.config.json` `outdated.allowlist`: installing 1.9.10 fails because the install's Socket security scanner gets a 403 from its upstream.
