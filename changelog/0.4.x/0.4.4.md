# 0.4.4 — 2026-11-08

## Added

- **`nutrition_grade`, `nova_group`, `ecoscore_grade`** ([#85](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/85)): `off_search_products` takes one value or an any-of array for each, and `ecoscore_grade` (Green-Score) is a new filter. The mirror serves grade lists exactly and indexes Green-Score from record version 2, so a Green-Score search is served from it only after a full reload has indexed it.
- **`off_get_product` `generic_name` and `nutrient_levels`** ([#87](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/87)): what the product is, and Open Food Facts' low/moderate/high verdict on fat, saturated fat, sugars, and salt, with `basis` (`as_sold` or `prepared`) naming the figures it describes.
- **`mirror_fields_unread`** (`off_get_product` output): when a mirror row predates those fields, the read goes live; if that fails or finds nothing, the stored row is served without them and this field names which were not read and why.
- **`ingredients_tag` and the `ingredients` facet** ([#88](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/88)): `off_search_products` filters on canonical ingredient IDs, answered from the text index, and refuses `additives_tag`. `off_browse_taxonomy` `facet: "ingredients"` resolves them, live only, with no offline sample.

## Changed

- **`page_size` cap 50 → 100** ([#86](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/86)): pages count at the size served, so `page_size: 100` with `page: 101` (results 10,001–10,100) is refused as `page_out_of_range`, where 0.4.3 served `page: 101` as results 5,001–5,050 at its cap of 50.
- **Mirror record version 2** ([#87](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/87)): a mirror runs a full reload of the export on its next refresh.
- **`text_index_snapshot`**: a text-path search carrying a grade filter says the grades are the index's, single grades included.
- **Green-Score label**: the `off_get_product` scores line and the `off_compare_products` Scores table label the grade "Green-Score", where they said "Eco-Score".

## Fixed

- **`off_browse_taxonomy` `search`** ([#84](https://github.com/cyanheads/openfoodfacts-mcp-server/issues/84)): the tag the term itself names (`US` → `en:united-states`) is listed first, and is added when the substring rule admits neither its ID nor its name (`plant based milk alternatives`), so a small `limit` no longer cuts it.

## Dependencies

- **`@cyanheads/mcp-ts-core`** ^0.13.18 → ^0.13.22. The mirror sync hands the framework's runner a store without its own `syncLease`, keeping every page write behind the server's mirror lock, and a connection dropped mid-body, now reported as a wrapped network error, still maps to the retryable `upstream_error`.
- **`engines.bun`** >=1.4.0 → >=1.4.4 (the framework's SQLite mirror store requires it).
- **`@biomejs/biome`** ^2.6.4 → ^2.6.6, **`vitest`** ^5.0.5 → ^5.1.0.
